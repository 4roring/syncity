# 설계 결정 기록

새 결정은 아래에 추가한다. 결정을 뒤집을 때는 기존 항목을 지우지 말고, 새 항목에서 이전 번호를 참조한다.

## D1. C/C++ 전용으로 시작
- **결정:** 분석 대상은 C/C++만. 다른 언어는 실제 수요가 생기면 검토한다.
- **이유:** 회사 프로젝트가 C/C++이고, 다른 언어는 활용 계획이 불확실하다. 파서를 언어별로 추상화하는 비용을 지금 낼 이유가 없다.

## D2. 파서는 tree-sitter-cpp, 자체 파서는 만들지 않는다
- **결정:** tree-sitter-cpp를 사용한다. libclang은 정확도가 필요해질 때 옵션으로 검토한다.
- **이유:** C++ 파서 직접 구현은 수년짜리 작업이다. 메트릭에는 근사 구조로 충분하다. tree-sitter는 매크로 등으로 문법이 깨져도 파싱을 계속하고, 빌드 설정(`compile_commands.json`)도 필요 없다.
- **보완:** 매크로 동일 길이 치환, 파일별 `error_ratio`로 파싱 품질을 노출한다.

## D3. `.c` 파일도 tree-sitter-cpp로 파싱
- **결정:** v1은 모든 확장자를 cpp 문법 하나로 파싱한다.
- **이유:** `.h`가 C인지 C++인지 판별할 수 없고, 문법이 하나면 노드 이름 표도 하나로 유지된다.
- **재검토 조건:** `.c` 파일의 `error_ratio`가 눈에 띄게 높으면(예: `class`, `new`를 식별자로 쓰는 코드) tree-sitter-c를 추가한다.

## D4. LLM 토큰 압축 모드는 범위에서 제외
- **결정:** 분석과 시각화에만 집중한다.
- **이유:** 경쟁 상대와 요구사항이 다른 별개 제품이고, 두 역할을 동시에 하면 복잡해진다. core/cli 분리 구조라서 나중에 exporter로 추가하기 쉽다.

## D5. Churn은 Phase 4에서 Perforce 기준으로
- **결정:** v1은 복잡도만 다룬다. churn은 `p4` CLI 기반 별도 서브커맨드로 추가한다.
- **이유:** 시각화 파이프라인을 먼저 검증하는 편이 리스크가 적다. Perforce 서버 조회는 캐시 설계가 필요하다.

## D6. 파일은 바이트로 읽는다
- **결정:** UTF-8 디코딩을 요구하지 않는다.
- **이유:** 회사 C/C++ 코드에는 CP949/EUC-KR 주석이 섞여 있을 가능성이 높다. UTF-8을 강제하면 파일 단위 실패가 대량으로 생긴다.

## D7. 폐쇄망 Windows에는 단일 exe로 반입
- **결정:**
  - 개발과 검증은 외부(인터넷 가능) PC에서 한다.
  - 회사에는 GitHub Actions(`windows-latest`, `x86_64-pc-windows-msvc`)로 빌드한 `syncity.exe` 하나만 반입한다.
  - CRT를 정적 링크(`-C target-feature=+crt-static`)해서 VC++ 재배포 패키지 없이 실행되게 한다.
- **이유:**
  - 회사는 폐쇄망이라 런타임이나 패키지를 설치하기 어렵고, Claude Code도 쓸 수 없다.
  - tree-sitter는 C 코드라서 빌드할 때 실행 파일 안에 들어가므로 외부 의존성이 없다.
- **결과:**
  - Windows 경로(`\`, 드라이브 문자, 긴 경로)를 처리해야 한다.
  - 출력 경로는 항상 `/`로 정규화한다 ([OUTPUT_SCHEMA](OUTPUT_SCHEMA.md)).
  - lizard 비교 검증은 외부 PC에서 픽스처와 공개 C++ 프로젝트로만 한다.

## D8. 파싱 품질 진단 기능(`diagnose`) 추가
- **결정:**
  - `syncity diagnose <DIR>` 서브커맨드를 만든다.
  - 출력 내용: `error_ratio` 상위 파일 목록, ERROR 노드 직전에 자주 나오는 식별자(매크로 후보)의 빈도.
  - 코드 본문은 출력하지 않는다.
- **이유:** 개발자(Claude)가 회사 코드를 볼 수 없다. 사용자가 회사에서 매크로 이름만 확인해 `strip_macros`에 추가하는 방식으로, 코드를 밖으로 가져오지 않고 파싱 품질을 개선한다.
